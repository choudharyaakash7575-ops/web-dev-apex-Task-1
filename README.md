# Web Development Internship - Task 1: Basics of Web Development

**ApexPlanet Software Pvt. Ltd. | HTML, CSS & JavaScript**

## About
A simple webpage that demonstrates the fundamentals of web development:

1. **HTML** - headings, paragraphs, an image and links (`index.html`)
2. **CSS** - colors, fonts, spacing and layout, plus a small-screen media query (`style.css`)
3. **JavaScript** - a button that shows an alert message when clicked (`script.js`)

## Project Structure
```
.
├── index.html
├── style.css
├── script.js
├── images/
│   └── hero.svg
└── README.md
```

## How to Run
Download or clone the repository and open `index.html` in any browser. No installation needed.
