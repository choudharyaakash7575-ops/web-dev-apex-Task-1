About This Page

This is a simple webpage I built as part of the Web Development Internship at ApexPlanet Software Pvt. Ltd. It shows the three building blocks of every website: HTML for structure, CSS for styling and JavaScript for interactivity.

The goal of Task 1 is to understand the basics: creating a page with headings, paragraphs, images and links, styling it with colors, fonts, spacing and layout, and adding a button that shows an alert message.

What I'm Learning

1. HTML - Structure

HTML uses tags like headings, paragraphs, images and links to define the content of a page.

2. CSS - Styling

CSS controls colors, fonts, spacing and layout, so the page looks clean and professional.

3. JavaScript - Interactivity

JavaScript makes the page respond to the user, for example by showing a message when a button is clicked.
